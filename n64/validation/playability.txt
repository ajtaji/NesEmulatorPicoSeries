MMC1, 20 kHz mono, independent DMC and raster deadlines
While the DMC holds a buffered byte, the next CPU memory fetch occurs on timer + (remaining bits - 1) * period. Stop CPU run-ahead before that edge. The fetch still reads the current PRG bank and charges four CPU cycles. The PPU may defer raster work until its own deadline. A CPU access that observes or changes video synchronizes the PPU first. The native 6502 path also batches immutable JMP-to-self loops within the existing CPU budget and reads enabled MMC1 SRAM directly. Disabled SRAM uses the normal open-bus handler.
